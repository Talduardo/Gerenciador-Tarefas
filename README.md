# ✅ Gerenciador de Tarefas

Este projeto foi desenvolvido em **Python** com o objetivo de servir como um **sistema de gerenciamento de tarefas**, funcionando como um checklist das atividades diárias.  
A aplicação permite adicionar, excluir e acompanhar tarefas em andamento, além de visualizar atividades concluídas, ajudando na organização pessoal e produtividade.

---

## 🎯 Objetivos:

- Ser um sistema para analisar suas atividades diárias.  
- Funcionar como um **checklist** simples e eficiente.  
- Permitir **adicionar tarefas** de forma prática.  
- Possibilitar **exclusão de tarefas** quando necessário.  
- Mostrar **tarefas em andamento**.  
- Exibir **atividades concluídas** para acompanhamento.
